# 📚 Stack Data Structure Implementations in C++

This repository contains multiple implementations of the **Stack Data Structure** in C++.

## Implementations

- Array-based Stack
- Vector-based Stack
- Template-based Stack (Vector)
- Linked List-based Stack
- STL List-based Stack

## Features

- LIFO (Last In First Out) concept
- Underflow handling
- Template support (Generic programming)
- Clean and structured code
- Memory-safe implementations (Linked List)
